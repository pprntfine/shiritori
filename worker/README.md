# つうちサーバー（じぶん専用）の つくりかた

「メッセージ・写真が とどかない ことが ある」の いちばんの げんいんは、
みんなで つかう 無料の 中継（ntfy.sh）の 回数せいげん です。
じぶん専用の つうちサーバーを つくると、通知は そちらを とおるので せいげんを うけません。

- お金: かかりません（Cloudflare の 無料プラン。1日 10万回まで）
- 中身: サーバーは 暗号文を そのまま わたす だけ。読めません・のこしません。
- つくるのは **1人だけ** で OK（アドレスは あいてにも じどうで つたわります）

## 1. Worker を つくる
1. https://dash.cloudflare.com に ログイン（アカウントが なければ つくる）
2. 左の「Workers & Pages」→「作成」→「Worker を作成」
3. 名前を `zatsugaku-push` に して「デプロイ」
4. 「コードを編集」を おす → 中身を ぜんぶ けして、この フォルダの
   `zatsugaku-push.js` の 中身を ぜんぶ はりつける →「デプロイ」

## 2. しまい場所（KV）を つくって つなぐ
1. 左の「ストレージとデータベース」→「KV」→「作成」
   名前は `zatsugaku-push-kv`（なんでも よい）
2. さっきの Worker `zatsugaku-push` を ひらく →「設定」→「バインディング」→「追加」
   →「KV 名前空間」
3. **変数名は `ZG`**（大文字・この とおりに）、KV は さっき つくった もの →「デプロイ」

## 3. うごいて いるか たしかめる
ブラウザで つぎを ひらく（〇〇 は じぶんの 名前の ところ）

    https://zatsugaku-push.〇〇.workers.dev/key

`{"key":"B…"}` の ような ながい 文字が でれば せいこう です。
`KV namespace ZG is not bound` と でたら、2. の 変数名を たしかめて ください。

## 4. アプリに いれる
1. 雑学王 の 裏メニュー → 設定 →「つうちサーバー」に
   `https://zatsugaku-push.〇〇.workers.dev` を いれて「ほぞん」
2. 「つうちサーバー：せってい ずみ ✓」と でれば OK
3. **2人とも** 「通知:オン」を おして おく（あいての スマホも とうろくが いります）
4. 設定の「とどけ てんけん」で ⑦ が「おくれた（1台）」に なれば かんせい

## うまく いかない とき
- アプリの 欄を **空に して ほぞん** すれば、もとの しくみ（ntfy.sh）に もどります。
- サーバーが こたえない ときは、アプリが じどうで 予備の 経路に まわします。
- 鍵（VAPID）は はじめて `/key` を ひらいた とき じどうで できて KV に しまわれます。
  KV を けすと 鍵が かわるので、そのときは 2人とも 設定で もう一度「ほぞん」して ください。

## しくみ（くわしい 人むけ）
| 道 | 中身 | こたえ |
|---|---|---|
| `GET /key` | — | `{key}` VAPID公開鍵 |
| `POST /sub` | `{topic, sub}` | `{ok:true}` |
| `POST /push` | `{topic, msg}` | `{ok:true, sent:N}` / `{ok:false, err:'no subscriber'}` |

- Web Push の 暗号は RFC8291（aes128gcm）、署名は RFC8292（VAPID/ES256）。外部ライブラリなし。
- 4096バイトに はいらない 大きい 本文は `zgm:N:!…`（しるし）に おきかえて 通知だけ 鳴らす
  （本文は ふつうの 経路で とどく。アプリ v276 と 同じ ふるまい）。
- 404/410 が かえった 端末は じどうで はずす。1トピック 4台まで。
- KV の 書きこみは 「とうろくが かわった とき」だけ（無料枠 1日1000回を つかいきらない）。
